Pingclair는 하나의 설정으로 HTTP/1.1, HTTP/2, HTTP/3를 함께 제공하고, ACME로 공개 인증서를 발급받아 갱신하며, 압축과 범위 요청을 지원하는 정적 파일 서비스를 제공합니다. 설정 언어인 Pingclairfile은 Caddyfile 관례를 따릅니다.

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 릴리스 상태

현재 릴리스는 **v0.2.0-rc.3**이며 릴리스 후보입니다. 이 문서의 각 페이지는 그 버전을 설명합니다. `v0.1.x` 계열은 더 이상 유지보수되지 않으며 보안 수정도 제공되지 않습니다. [프로젝트 상태](/ko/project/status/)에 지원하는 기능, 거부되는 설정, 그리고 태그 시점에 알려진 결함을 정리해 두었습니다.

## 📊 성능

Pingclair는 nginx, Caddy와 같은 호스트에서 측정합니다. 각 후보는 2개 CPU로 제한하고 동일한 부하를 사용합니다. 실측값, 측정 조건, 그리고 Pingclair가 뒤처지는 행까지 [성능 측정](/ko/project/benchmarks/)에 공개합니다.

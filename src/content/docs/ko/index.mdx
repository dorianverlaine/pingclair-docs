Pingclair는 하나의 설정으로 HTTP/1.1, HTTP/2, HTTP/3를 모두 서비스하고, ACME로 공개 인증서를 발급받아 갱신하며, 압축과 범위 요청을 지원하는 정적 파일 서버로도 동작합니다. 설정 언어인 Pingclairfile은 Caddyfile의 관례를 따릅니다.

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 릴리스 상태

현재 릴리스는 릴리스 후보인 **v0.2.0-rc.3**이며, 이 문서는 이 릴리스를 기준으로 합니다. `v0.1.x` 계열은 더 이상 유지보수되지 않으며 보안 수정도 제공되지 않습니다. 지원하는 기능, 거부하는 설정, 태그 시점에 알려진 결함은 [프로젝트 상태](/ko/project/status/)에 정리되어 있습니다.

## 📊 성능

Pingclair는 같은 호스트에서 nginx, Caddy와 함께 측정하며, 모든 후보를 CPU 2개로 제한하고 동일한 부하를 겁니다. 측정값과 측정 조건, 그리고 Pingclair가 더 느린 항목까지 [벤치마크](/ko/project/benchmarks/)에 공개되어 있습니다.

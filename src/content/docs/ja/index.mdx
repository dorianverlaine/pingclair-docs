Pingclair は 1 つの設定から HTTP/1.1、HTTP/2、HTTP/3 を配信し、ACME で公開証明書を取得して更新し、圧縮とレンジリクエストに対応した静的ファイル配信を行います。設定言語である Pingclairfile は Caddyfile の慣習に従います。

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 リリース状況

現在のリリースは **v0.2.0-rc.3** で、リリース候補です。本サイトの各ページはこのバージョンを説明しています。`v0.1.x` 系はメンテナンスされておらず、セキュリティ修正も提供されません。[プロジェクト状況](/ja/project/status/)に、対応している機能、拒否される設定、タグ付け時点で判明している不具合をまとめています。

## 📊 性能

Pingclair は nginx および Caddy と同一ホスト上で測定しています。各候補は 2 CPU に制限し、まったく同じ負荷をかけています。実測値、測定条件、そして Pingclair が劣っている行も[性能測定](/ja/project/benchmarks/)で公開しています。

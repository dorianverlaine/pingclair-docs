Pingclair 用一份配置同时提供 HTTP/1.1、HTTP/2 和 HTTP/3，通过 ACME 获取并续期公网证书，
并以压缩和范围请求的方式提供静态文件。它的配置语言 Pingclairfile 遵循 Caddyfile 的约定。

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 发布状态

当前版本是 **v0.2.0-rc.3**，属于候选版本。本站各页描述的就是这个版本。`v0.1.x` 系列已停止维护，
不再接收安全修复。[项目状态](/zh-CN/project/status/)列出了支持什么、拒绝什么，以及打标签时已知的缺陷。

## 📊 性能

Pingclair 与 nginx、Caddy 在同一台主机上进行测量，每个参与者都限制为两个 CPU，并使用完全相同的负载。
实测数字、测量条件，以及 Pingclair 落后的那几行，都发布在[性能测量](/zh-CN/project/benchmarks/)中。

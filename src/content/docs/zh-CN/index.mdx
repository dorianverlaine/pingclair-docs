一份配置文件，同时提供 HTTP/1.1、HTTP/2 和 HTTP/3 服务。Pingclair 通过 ACME 自动获取和续期证书，
静态文件支持压缩和范围请求。配置语言 Pingclairfile 沿用 Caddyfile 的写法。

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 发布状态

当前版本为 **v0.2.0-rc.3**（候选版本），本站所有页面均基于此版本编写。`v0.1.x` 已停止维护，不再提供安全修复。
[项目状态](/zh-CN/project/status/)页列出了已支持的功能、明确拒绝的功能，以及发版时已知的缺陷。

## 📊 性能

Pingclair 和 nginx、Caddy 在同一台主机上测量，每个被测对象限制为两个 CPU、使用完全相同的负载。
实测数据、测量条件以及 Pingclair 表现较差的项目，均发布在[性能测量](/zh-CN/project/benchmarks/)页面。

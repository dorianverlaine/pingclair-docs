Pingclair 用一份設定同時提供 HTTP/1.1、HTTP/2 與 HTTP/3，透過 ACME 取得並自動續期公開憑證，也能以壓縮與 range 請求提供靜態檔案。它的設定語言 Pingclairfile 沿用 Caddyfile 的慣例。

```caddyfile
example.com {
    encode zstd gzip
    reverse_proxy 10.0.0.10:8080 10.0.0.11:8080
}
```

## 📌 發行狀態

目前的發行版是 **v0.2.0-rc.3**，屬於 release candidate，本站各頁描述的就是這個版本。`v0.1.x` 系列已停止維護，不會再收到任何安全修正。[專案狀態](/zh-TW/project/status/)列出了支援的功能、會被拒絕的設定，以及標記版本時已知的缺陷。

## 📊 效能

Pingclair 與 nginx、Caddy 在同一台主機上比較，每個候選者都限制在兩顆 CPU，負載完全相同。實測數字、量測條件，以及 Pingclair 較慢的那幾列，都公開在[效能基準測試](/zh-TW/project/benchmarks/)。
